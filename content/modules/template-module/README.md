# Руководство по созданию нового модуля

Вы можете легко добавлять любые новые функции в расширение (например: калькулятор рейтов, автообновление грузов, подсветка штатов, расчет расстояний и т.д.).

## Как добавить новый модуль за 3 шага:

### Шаг 1: Скопируйте папку с модулем
1. Скопируйте папку `content/modules/template-module/` и назовите её именем новой функции (например `rate-calculator`).
2. В файле `index.js` измените:
   - `this.id = 'rate-calculator';`
   - `this.name = 'Калькулятор ставки ($/миля)';`
   - `this.description = 'Автоматически рассчитывает ставку за милю для каждого груза.';`

### Шаг 2: Напишите логику
В методе `enable()` реализуйте нужный функционал:
- `domObserver.watch(selector, callback)` — позволяет реагировать на появление любых элементов в DAT One даже при динамической подгрузке страниц (SPA).
- `StorageService.get(...)` и `StorageService.set(...)` — для сохранения данных в памяти браузера.
- `eventBus.emit(...)` и `eventBus.on(...)` — для общения между модулями.

В методе `disable()` удаляйте все созданные кнопки и интерфейсы, чтобы при выключении модуль не оставлял следов.

### Шаг 3: Зарегистрируйте модуль
Откройте файл `content/content-main.js` и добавьте две строчки:

```javascript
// 1. Импортируйте ваш модуль
import { rateCalculatorModule } from './modules/rate-calculator/index.js';

// 2. Зарегистрируйте его в менеджере
moduleManager.register(rateCalculatorModule);
```

Готово! Новый модуль появится в меню расширения, получит свой переключатель Вкл/Выкл и будет сохранять свои настройки!
