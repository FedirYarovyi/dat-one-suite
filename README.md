# DAT One Suite — Расширение для dat.one

Модульное расширение для Chrome / Edge / Brave, созданное специально для оптимизации работы на логистическом портале **DAT One** (`dat.one` / `one.dat.com`).

---

## 🚀 Основные возможности

### 1. 🗂 Скрытие боковой панели (Sidebar Toggle)
* Освобождает полезное пространство экрана для таблицы грузов и деталей сделок.
* Аккуратная плавающая кнопка **«Меню»** на левом краю экрана.
* Быстрое сворачивание/разворачивание горячей клавишей **`Alt + S`**.
* Поддержка пользовательского CSS-селектора в настройках (если DAT обновит верстку).
* Автоматически запоминает состояние (свернуто/развернуто) между страницами.

### 2. 📝 Умные заметки по компаниям (Company Notes)
* **Многофакторная идентификация**: компания автоматически распознается по любому из признаков:
  * **MC #** (например, `123456`)
  * **DOT #**
  * **Телефон** (любой формат: `(800) 555-0199`, `800-555-0199` и т.д.)
  * **Email** (например, `dispatch@broker.com`)
  * **Название компании** (с умной очисткой от LLC, Inc, Co)
* **Статусы и бейджи**:
  * ⛔ **DNU (Do Not Use)** — красный пульсирующий бейдж с предупреждением о недобросовестных брокерах/перевозчиках.
  * 🟢 **Хороший / Надежный** — быстро платит, проверенный партнер.
  * 🟡 **Внимание** — особенности оформления, строгие требования к чекинам.
  * 🔵 **Обычный / Инфо** — контакты конкретных диспетчеров, требования по ставкам.
* **Автоматическое встраивание в интерфейс**:
  * **Прямо в таблице грузов**: компактные цветные кружочки (🟢, 🔵, 🟡, ⛔) для компаний и номеров телефонов, а email при наличии заметки полностью оборачивается в цветную плашку с кнопкой `Note`. Если на один контакт записано несколько заметок, отображается статус самого позитивного брокера.
  * **В карточке груза**: подробные бейджи с превью цитаты заметки и кнопки `+` для быстрого добавления.
* Быстрый вызов по **`Alt + N`**.

### 3. 🧩 Модульная архитектура
* Полностью модульный код без сборщиков и зависимостей (чистый современный JavaScript ES6 Modules).
* Встроен готовый шаблон `content/modules/template-module/` — вы можете добавлять новые функции (например, калькулятор ставки $/миля, подсветку грузов, автообновление) за несколько минут.

### 4. 💾 Резервное копирование и экспорт
* Экспорт всей базы заметок в файл **JSON** в один клик.
* Импорт заметок на другом компьютере с автоматическим объединением данных.

## 📦 Установка в браузер (пошагово)

1. Откройте браузер (**Google Chrome**, **Brave** или **Microsoft Edge**).
2. Перейдите на страницу расширений:
   * Chrome: скопируйте в адресную строку `chrome://extensions` и нажмите Enter.
   * Edge: `edge://extensions`
   * Brave: `brave://extensions`
3. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).
4. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked) в левом верхнем углу.
5. Выберите папку с репозиторием (папку `DAT_One_Notes_Extension`, содержащую файл `manifest.json`).
6. Расширение **DAT One Suite** появится в списке расширений!
7. Для удобства закрепите иконку расширения на панели браузера (кнопка в виде пазла справа от адресной строки).

## ⌨️ Горячие клавиши

| Сочетание клавиш | Действие |
|---|---|
| **`Alt + S`** | Свернуть / развернуть боковую панель DAT One |
| **`Alt + N`** | Открыть редактор заметки для текущего груза / поиск |

*(При желании комбинации клавиш можно изменить в `chrome://extensions/shortcuts`)*.

## 🛠 Как устроена структура проекта

```text
DAT_One_Notes_Extension/
├── manifest.json                  # Конфигурация расширения Chrome Manifest V3
├── icons/                         # Иконки расширения (16x16, 48x48, 128x128)
├── background/
│   └── service-worker.js          # Фоновый процесс (горячие клавиши, настройки)
├── popup/                         # Окно управления при клике на иконку
│   ├── popup.html                 # Интерфейс (список заметок, фильтры, бэкап)
│   ├── popup.css                  # Стили всплывающего окна
│   └── popup.js                   # Логика поиска, редактирования и экспорта
├── content/
│   ├── loader.js                  # Загрузчик модулей
│   ├── content-main.js            # Точка входа: регистрация и запуск модулей
│   ├── content.css                # Общие стили для страниц dat.one
│   ├── core/                      # Системное ядро расширения
│   │   ├── module-manager.js      # Менеджер жизненного цикла модулей
│   │   ├── dom-observer.js        # Отслеживание изменений динамического DOM (SPA)
│   │   ├── storage.js             # Асинхронная работа с chrome.storage
│   │   └── event-bus.js           # Шина событий между модулями
│   └── modules/                   # Папка модулей функций
│       ├── sidebar-toggle/        # Модуль 1: Скрытие боковой панели
│       ├── company-notes/         # Модуль 2: Заметки о компаниях
│       └── template-module/       # Шаблон для ваших собственных новых функций!
```

## 💡 Как добавить свой новый модуль (новую функцию)

Подробное руководство находится в файле [`content/modules/template-module/README.md`](./content/modules/template-module/README.md).

Краткий алгоритм:
1. Скопируйте папку `template-module` и назовите её именем новой функции (например `rate-calculator`).
2. В файле `index.js` укажите `id`, `name`, `description` и логику в `enable()`.
3. В файле `content/content-main.js` добавьте:
   ```javascript
   import { myNewModule } from './modules/my-new-module/index.js';
   moduleManager.register(myNewModule);
   ```
4. Обновите расширение в `chrome://extensions` — новый модуль заработает автоматически!
